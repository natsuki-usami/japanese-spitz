# Debug-Viewer-Country Header

`Debug-Viewer-Country` リクエストヘッダーを、指定したドメインにだけ付与する開発用 Chrome 拡張機能（Manifest V3）。
ModHeader の代替として、このヘッダー専用に作ったもの。

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

## 使い方

ツールバーのアイコンからポップアップを開く。

| 設定 | 動作 |
| --- | --- |
| OFF | ヘッダーを付与しない |
| JP | `Debug-Viewer-Country: JP` を付与する |
| JP以外 | 入力欄の値（初期値 `US`）を付与する |
| 対象ドメイン | 1 行に 1 つ記述する（例: `example.com`）。サブドメインも対象 |

- 設定は `chrome.storage.local` に保存され、ブラウザを再起動しても残る
- 対象ドメインが空の場合、ヘッダーは付与されない

## 設計方針

- **ドメイン限定**: 全サイトにヘッダーが乗って意図しない送信先へ漏れるのを防ぐため、対象ドメインを必須にしている
- **外部通信なし**: ネットワーク通信を行うコードは含まない
- **ヘッダー固定**: 扱うのは `Debug-Viewer-Country` のみ。任意ヘッダーの追加・変更はできない

## 権限

| 権限 | 理由 |
| --- | --- |
| `declarativeNetRequest` | リクエストヘッダーの書き換え（`modifyHeaders`） |
| `storage` | 設定の保存 |
| `host_permissions: <all_urls>` | `modifyHeaders` の仕様上、ホストを絞れないため。実際に書き換えるのは対象ドメインのみ |

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `manifest.json` | 拡張機能の定義 |
| `popup.html` | ポップアップの UI |
| `popup.js` | 設定の保存とヘッダー書き換えルールの登録 |
